# Self-hosted frontend assets

Bundled with the repo — **no runtime CDN** for Chart.js or fonts.

| Path | Package | Version |
|------|---------|---------|
| `chart.js/chart.umd.min.js` | Chart.js | 4.4.6 |
| `../fonts/` | Inter, Playfair Display, JetBrains Mono (@fontsource) | see download script |

Re-download after clone or upgrade:

```bash
bash scripts/download-frontend-vendor.sh
```
