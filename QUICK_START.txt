================================================================================
TROUBLESHOOTING
================================================================================

"Connection refused" in setup.php
→ Check .env file has correct database credentials
→ DB_HOST should be: sql211.infinityfree.com

"Table already exists" error
→ This is fine! Means schema was already created
→ You can proceed with seeding

Setup page shows 404
→ File wasn't uploaded correctly
→ Should be at: /htdocs/setup.php (not subdirectory)

Dashboard shows blank/error
→ Setup wasn't completed successfully
→ Go back to verify-deployment.php and check for red ❌
